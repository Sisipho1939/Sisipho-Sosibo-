# 🌦️ Johannesburg Live Weather Pipeline

> Built entirely on my phone 📱 | South Africa 🇿🇦

### 🔍 What This Project Does
Real-time ETL pipeline:
1. EXTRACTS live weather for JHB from API
2. LOADS into Parquet + SQLite Data Lake
3. QUERIES hottest hour with SQL

### 🛠️ Tech Stack
Python | Pandas | SQL | Parquet | API

### 📁 Repo Structure
- weather_pipeline.py - Live JHB Weather ETL
- Salon.sql - Salon Business Analysis
- dags/ - Airflow DAGs
- Load_to_sql.py - SQL Loader
- transform.py - Data Transformation
